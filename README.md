# WFP-Food-Prices-EDA
# 🌍 Exploratory Analysis of Global Food Prices Using WFP Dataset

This project analyzes global food price data from the World Food Programme (WFP) covering over 1.8 million records from 1990 to 2021. Using Python, the project explores trends, affordability, volatility, and correlations in food pricing, with a focused lens on four countries: Turkey, Iran, Iraq, and Syria.

## 🧰 Tools and Technologies

- Python (Pandas, Matplotlib, Seaborn, NumPy, SciPy)
- Jupyter Notebook
- Git & GitHub

## 📊 Key Objectives

1. **Data Cleaning & Preprocessing**  
   - Handle nulls, duplicates, and inconsistent columns
   - Normalize price values to USD

2. **Price Range Distribution**
   - Categorize prices into bins and assess global affordability

3. **Temporal Analysis**
   - Time-series trends of median food prices (1990–2021)

4. **Country-Level Comparison**
   - Analyze Rice, Lentils, and Sugar prices in Turkey, Iran, Iraq, Syria

5. **Affordability Metrics**
   - Work hours (based on minimum wage) needed to buy 1kg of rice

6. **Outlier Detection**
   - IQR and Z-score applied to Syria's price data

7. **Correlation Analysis**
   - Cross-country and intra-country price relationships

## 📈 Sample Visualizations

- Bar Charts (Price range, data density)
- Time Series Plots (Median prices over time)
- Heatmaps (Cross-country price correlation)
- Boxplots and Histograms (Price distribution with outliers)
- Scatter plots (Commodity comparisons)
- Pie chart (Top 10 expensive food items in Turkey)

## 🌐 Dataset Source

- 📦 [WFP Food Prices Dataset (1990–2021)](https://data.humdata.org/dataset/wfp-food-prices)
